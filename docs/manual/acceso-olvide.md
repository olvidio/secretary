# Olvidé la contraseña

- Ámbito: todos
- Ruta: `/olvide-contrasena`, `/olvide-contrasena-enviado`, `/restablecer-contrasena`
- Menú: No sale en el menú: el enlace está en la pantalla de entrar
- Quién: cualquier persona que no recuerde la contraseña

## Para qué sirve

Sirve para elegir una contraseña nueva sin pedir ayuda a quien administra el programa. El enlace llega al correo confirmado de la cuenta.

## Cómo se usa

1. En «Entrar», pulsar «Olvidé la contraseña».
2. Escribir el alias o el correo y pulsar «Enviar enlace».
3. Abrir el mensaje. Si ese correo tiene varias cuentas, el mensaje trae un enlace por cada una, con el nombre de la cuenta.
4. Elegir la contraseña nueva, repetirla y pulsar «Guardar contraseña».
5. Volver a «Entrar» con la contraseña nueva. Si la cuenta es de secretario, el programa pide otra vez el código de seis dígitos.

## Reglas que conviene saber

- El aviso de la pantalla es siempre el mismo, haya o no una cuenta con ese dato.
- El enlace solo se envía si la cuenta está activa y el correo está confirmado.
- Caduca a las dos horas y solo puede usarse una vez. Si se pide otro, el anterior deja de valer.
- La contraseña nueva tiene al menos seis caracteres y hay que escribirla dos veces igual.
- Al guardar la contraseña nueva se quita también el bloqueo de quince minutos por intentos fallidos.
- El programa no entra solo: después hay que identificarse.

## Problemas frecuentes

- **«El enlace no es válido o ha caducado. Solicite otro.»**: ha pasado el plazo, el enlace ya se usó o se pidió uno nuevo. Hay que solicitar otro desde «Olvidé la contraseña».
- **«Las contraseñas nuevas no coinciden»** o **«La contraseña nueva debe tener al menos 6 caracteres»**: volver a escribirlas. El enlace sigue valiendo.
- **No llega ningún mensaje**: revisar el correo no deseado. Si la cuenta nunca confirmó el correo, el enlace no se envía; hay que abrir el del alta o pedir que lo reenvíen en la pantalla de registro. Si el servidor de correo falla, la pantalla de «Olvidé la contraseña» muestra el error en lugar del aviso de éxito.
