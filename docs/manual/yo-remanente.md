# Remanente

- Ámbito: persona
- Ruta: `/yo/remanente`
- Menú: nombre de la esquina → Remanente (junto a Mail y Contraseña)
- Quién: cualquier persona

## Para qué sirve

Sirve para fijar el dinero que se queda en el banco o en la cuenta personal y no se manda al centro. En la remesa no viaja el saldo entero de caja y banco: viaja el **disponible**, que es ese saldo menos el remanente.

## Cómo se usa

1. Abrir el nombre de la esquina y pulsar **Remanente** (junto a Mail y Contraseña).
2. Escribir la cantidad que debe quedarse (por ejemplo 200). Vacío o cero significa que se envía todo el saldo.
3. Pulsar **Guardar**.
4. En **Remesa**, revisar el saldo, el remanente y el disponible que se envía antes de cerrar el mes.

## Reglas que conviene saber

- El remanente es una cantidad fija. No se recalcula cada mes: la define la persona y se aplica a todas las remesas.
- El disponible de un mes es el saldo de caja y banco a la fecha de cierre, menos el remanente. Si el saldo no cubre el remanente, se envía cero.
- La caja y el banco propios siguen sin viajar como movimientos. Lo que cambia es el importe que el centro puede usar para sustituir el disponible.
- Cambiar el remanente no modifica una remesa ya enviada. Hay que volver a enviar el mes para que cuente el importe nuevo.

## Problemas frecuentes

- **«El remanente no puede ser negativo»**: se ha escrito un importe menor que cero.
- **«La cantidad debe ser numérica»** o **«Falta la cantidad»**: el importe no se entiende. Usar cifras, con coma o punto decimal.
- **El centro ha recibido el saldo entero**: el remanente estaba a cero, o el mes se envió antes de guardarlo. Guardar el remanente y volver a enviar.
